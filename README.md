## Key Features
- **Interactive Custom PC Builder:** Real-time CPU, Motherboard, GPU, RAM, Storage, and PSU compatibility checks with live wattage calculation.
- **Side-by-Side Hardware Comparison:** Compare specifications, clock speeds, and pricing across multiple PC components and peripherals.
- **Persistent Shopping Cart & Wishlist:** LocalStorage-backed cart management, promo code discounts (`GEAR10`), checkout validation, and order tracking.
- **Flash Deals & Benchmarks:** Live countdown timers, stock indicators, and 1080p/1440p/4K gaming FPS benchmarks.
